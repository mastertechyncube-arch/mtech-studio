MTech Studio install pack

Upload every file in this folder to any web host that uses https (GitHub Pages, Netlify, Cloudflare Pages, your own hosting).
Keep index.html, sw.js and manifest.webmanifest together in the same folder.
Then open the address on your phone or laptop and choose Install app (Chrome) or Add to Home Screen (Safari).
Your projects are NOT in this pack. Use Download full backup in the old studio and Restore in the new one.
